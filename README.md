# Зацеп

Личная «качалка-комбайн» для видео и музыки на своём компьютере или сервере: вставляешь ссылку (YouTube, SoundCloud, TikTok, Instagram, X, VK, Rutube, Twitch, Bandcamp и всё, что знает yt-dlp), выбираешь формат и качество — получаешь файл.

> Сервис нужен для личного использования контента, на который у тебя есть права. Контент под DRM не скачивается.

## Запуск

Нужен Node.js 22+ (проверено на 26). Зависимостей нет — база SQLite встроена в Node, ничего настраивать не надо.

```bash
npm install
npm run tools
npm start
```

`npm run tools` скачивает yt-dlp (и ffmpeg для Windows) в папку `./bin`. На macOS/Linux поставь ffmpeg сам: `brew install ffmpeg` / `sudo apt install ffmpeg`.

Открой http://localhost:3000. В консоли напечатается и адрес для телефона в той же Wi-Fi сети.

Вход отключён: просто открой сайт, вставь ссылку — файл скачается на твоё устройство и не останется на сервере (переключатель «Оставить копию на сервере» — если нужна библиотека). Аккаунты по приглашениям можно вернуть командой `REQUIRE_LOGIN=1 npm start` (логин «Пользователь», пароль 12345678).

> Без входа сайтом может пользоваться любой, кто до него достучится. Не открывай порт в интернет без защиты.

Для телефона, «Поделиться» из приложений и установки как приложение нужен HTTPS:

```bash
npm run https
```

Сертификат самоподписанный — в браузере нажми «Дополнительно → Перейти на сайт».

## Облако

GitHub Pages не умеет запускать yt-dlp, поэтому сервер надо где-то запускать: [Render](https://render.com/deploy?repo=https://github.com/flksflsafla262-dot/zatsep) (есть Dockerfile и ender.yaml) или GitHub Codespaces (.devcontainer). YouTube часто блокирует адреса дата-центров — тогда загрузи cookies.txt в «Настройки».

## Что внутри

- Скачивание: одна ссылка или пачка, выбор видео/аудио/картинки, качество (1080p60, 4K…), MP3/M4A/OPUS/FLAC/WAV, вырезка фрагмента, теги и обложка, субтитры, SponsorBlock.
- Очередь (3 параллельно), пауза, отмена, повтор; живой прогресс; yt-dlp сам обновляется раз в сутки.
- Аккаунты: владелец + друзья по одноразовым приглашениям (7 дней), лимиты, временные ссылки без регистрации, общая папка «Для всех».
- Свои файлы: загрузка кусками с докачкой, конвертация через ffmpeg, ZIP потоком.
- Плееры: видео (клавиши, двойной тап, PiP, субтитры) и музыка (очередь, мини-плеер, «Сейчас играет», Media Session).
- Instagram, закрытые видео и «подтвердите, что вы не бот»: загрузи `cookies.txt` в «Настройки».
