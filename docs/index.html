Зацеп

Вставил ссылку — файл сразу скачался на твоё устройство. YouTube, SoundCloud, TikTok, VK, Rutube, X и сотни других сайтов. Без входа.

Почему это не просто страница на GitHub

GitHub Pages отдаёт только статику и не умеет запускать программы. А скачивание видео делает yt-dlp + ffmpeg — им нужен сервер. Поэтому Зацеп запускается у тебя (или в облаке), а скачанное уходит прямо в твой браузер.

1. На своём компьютере — лучший вариант

git clone https://github.com/flksflsafla262-dot/zatsep.git
cd zatsep
npm install
npm run tools
npm start

Нужен Node.js 22+. Дальше открой сайт и вставляй ссылки.

Открыть localhost:3000Скачать Node.js

2. В облаке, в два клика

Свой сервер с публичной ссылкой. Минус: YouTube часто блокирует адреса дата-центров, тогда нужны cookies (Настройки → Cookies).
