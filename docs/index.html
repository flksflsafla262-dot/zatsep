Вставь ссылку

YouTube, SoundCloud, TikTok, VK, Rutube, X и сотни других сайтов. Скачивает GitHub — файл придёт прямо на твоё устройство.

    Как это работает

    Сайт отправляет ссылку в GitHub (откроется вкладка с готовым запросом — нажми зелёную кнопку Submit new issue, нужен бесплатный аккаунт GitHub). Серверы GitHub качают файл через yt-dlp и кладут его во временный релиз, а эта страница сама запускает скачивание на твоё устройство. Файлы удаляются через пару часов. Лимит — 1,9 ГБ на файл.

    YouTube часто не пускает серверы GitHub («подтвердите, что вы не бот») — тогда помогает cookies.txt в секрете репозитория YT_COOKIES или запуск Зацепа на своём компьютере (инструкция).
